# เรียงลำดับ Work Status และย้ายตำแหน่งช่องในฟอร์ม

หน้านี้สำหรับผู้ดูแลระบบ (Admin) อธิบายวิธีจัดลำดับ **Work Status** (สถานะงานในแคตตาล็อกสถานะ)
ให้ตรงกับลำดับขั้นตอนงานของทีม PSF และวิธีย้ายช่อง (field) ในฟอร์มไปยังตำแหน่งที่ต้องการในครั้งเดียว
ใช้กับระบบตั้งแต่ 24 ตุลาคม 2026 (issue #115)
รายละเอียดทางเทคนิคอยู่ที่ [Status catalog](../status-catalog-and-manual-updates.md#status-order-24-october-2026)
และ [current implementation](../current-implementation.md)

## เรียงลำดับ Work Status

ทำที่เมนู **Administration → Status Management**

1. คอลัมน์แรกของตารางชื่อ **Position** แสดงลำดับปัจจุบันของแต่ละ Work Status เป็นตัวเลขในช่องกรอก
   เลข 1 คือ Work Status แรกต่อจาก Draft
2. พิมพ์ตำแหน่งใหม่ในช่องของสถานะที่ต้องการย้าย แล้วกดปุ่ม **Move** หรือกด Enter
3. ระบบบันทึกทันทีและขึ้นข้อความ "Status catalog updated." สถานะนั้นย้ายไปอยู่ตำแหน่งที่พิมพ์
   สถานะอื่นเลื่อนลงหรือขึ้นหนึ่งตำแหน่งเพื่อเว้นที่ให้ ไม่ต้อง Publish

ตัวอย่าง: มี Work Status 16 รายการ ถ้าพิมพ์ 1 ที่แถว `0% -- Rejected (Cancel Request)` แล้วกด Move
สถานะนี้จะขึ้นไปอยู่บนสุดต่อจาก Draft และสถานะที่เคยอยู่ตำแหน่ง 1 ถึง 15 จะเลื่อนลงไปเป็น 2 ถึง 16

ข้อควรรู้

- **Draft อยู่บนสุดเสมอ** แถว Draft แสดงคำว่า "Always first" และไม่มีช่องให้ย้าย
- ตำแหน่งต้องเป็นจำนวนเต็มตั้งแต่ 1 ถึงจำนวน Work Status (ไม่นับ Draft) ถ้าพิมพ์ค่าอื่น เช่น 0, 1.5,
  เลขที่เกินจำนวน หรือเว้นว่าง ระบบจะไม่ย้ายและขึ้นข้อความใต้ช่อง เช่น "Enter a whole number from 1 to 16."
- การเรียงลำดับ **ไม่เปลี่ยน** สถานะของคำขอใด ๆ ชื่อสถานะ ประเภท (Open work / Completed / Cancel)
  ผู้รับอีเมลตาม **Status Email Policy** หรือสถานะที่เป็นตัวปลด **PSF Visibility Release** (Trigger)
  และไม่ส่งอีเมล
- ลำดับนี้เป็นลำดับการแสดงผลเท่านั้น ไม่ได้บังคับว่าคำขอต้องเดินตามลำดับ ผู้ใช้ยังเลือกสถานะได้ตามสิทธิ์เดิม
- ถ้าผู้ดูแลอีกคนแก้แคตตาล็อกสถานะไปก่อนหลังจากที่คุณเปิดหน้านี้ ระบบจะไม่บันทึกของคุณและขึ้นข้อความ
  "The workflow status catalog changed. Reload and try again." พร้อมโหลดลำดับล่าสุดมาให้
  ให้ตรวจลำดับที่เห็นแล้วย้ายใหม่ถ้ายังจำเป็น ไม่มีการเขียนทับงานของอีกคนโดยไม่รู้ตัว

### ลำดับนี้ใช้ที่ไหนบ้าง

- ตาราง Status Management
- ตัวกรอง Status ในหน้า Dashboard, Requests และ Export to Excel
  (ชื่อสถานะเก่าที่ยังอยู่ในคำขอ เช่น ของ Imported Request ต่อท้ายรายการในตัวกรอง)
- รายการ Status ในส่วน Action center ของหน้า Request Detail สถานะปัจจุบันของคำขออยู่ในตำแหน่งของมันตามลำดับ
  (ถ้าสถานะปัจจุบันไม่อยู่ในแคตตาล็อกแล้ว จะแสดงเป็นรายการแรก)

ลำดับถูกเก็บในฐานข้อมูลและคงอยู่หลังรีสตาร์ตระบบ แต่ **Initial Data Load** จะตั้งลำดับกลับเป็นลำดับของตัวเลือก
Status ใน workbook (ชีต `Column_Mapping`)

## ย้ายตำแหน่งช่องในฟอร์ม

ทำที่เมนู **Administration → Form Management** เลือกฟอร์ม Requester Information หรือ PSF Created Information
แล้วเปิดเวอร์ชันที่เป็น Draft (ถ้ายังไม่มี ให้กด **Duplicate as draft** จากเวอร์ชันที่ใช้อยู่)

1. แต่ละแถวของช่องในฟอร์มมีช่องกรอกตำแหน่ง (แสดงตำแหน่งปัจจุบัน) และปุ่ม **Move** ต่อจากปุ่ม Edit และปุ่มลูกศรขึ้น/ลง
2. พิมพ์ตำแหน่งใหม่แล้วกด **Move** หรือกด Enter ช่องนั้นย้ายไปตำแหน่งที่พิมพ์ในครั้งเดียว ช่องอื่นเลื่อนตาม
3. ตำแหน่งนับ **ภายใน section ของช่องนั้น** ต้องเป็นจำนวนเต็มตั้งแต่ 1 ถึงจำนวนช่องใน section
   ค่าอื่นจะไม่ย้ายและขึ้นข้อความใต้แถว เช่น "Enter a whole number from 1 to 12."
   ถ้าต้องการย้ายช่องไปอีก section ให้ใช้ Advanced · Edit schema JSON
4. ปุ่มลูกศรขึ้น/ลงยังใช้ย้ายทีละหนึ่งตำแหน่งได้เหมือนเดิม
5. การย้ายยังอยู่ในหน้าจอเท่านั้นจนกว่าจะกด **Save draft** แล้ว **Publish**
   เมื่อ Publish จะได้ Form Version ใหม่ซึ่งใช้กับคำขอใหม่ Draft ที่มีอยู่ใช้ Form Version เดิมจนกว่าผู้สร้างจะอัปเกรด
   และคำขอที่ส่งแล้วยังใช้ฟอร์มที่บันทึกไว้ตอนสร้าง
