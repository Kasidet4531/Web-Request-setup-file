# หมวดไฟล์แนบ (Attachment Category)

หน้านี้สำหรับผู้ดูแลระบบ (Admin) อธิบายว่าระบบแบ่งไฟล์แนบ (Attachment) ของ PSF Request
เป็นหมวดอย่างไร ใช้กับระบบตั้งแต่ 24 ตุลาคม 2026 (issue #122,
[ADR 0022](../adr/0022-attachment-categories-and-revise-file-copy.md))
รายละเอียดทางเทคนิคอยู่ที่ [Request Attachments](../request-attachments.md#attachment-categories)

## ระบบแบ่งไฟล์อย่างไร

ไฟล์แนบทุกไฟล์อยู่ในหมวดใดหมวดหนึ่งจาก 3 หมวด โดยระบบดูจาก **ชื่อไฟล์** เท่านั้น
ผู้อัปโหลดไม่ต้องเลือกหมวด และตัวพิมพ์เล็ก/ใหญ่ไม่มีผล

| หมวด | ไฟล์ที่อยู่ในหมวดนี้ | ตัวอย่าง |
| --- | --- | --- |
| **Map Layout File** (ไฟล์ผัง wafer map) | ชื่อลงท้ายด้วย `.xml`, `.dpl`, `.lay`, `.tpl` หรือ `.mdf` รวมไฟล์ E142 | `E142_map.XML`, `wafer.dpl` |
| **FPC Layout File** (ไฟล์ Excel ของ PCSF) | ชื่อขึ้นต้นด้วย `PCSF` **และ** ลงท้ายด้วย `.xls`, `.xlsx` หรือ `.xlsm` | `pcsf_ABC.xlsm`, `PCSF ABC.XLS` |
| **Other** (ไฟล์อื่น ๆ) | ไฟล์ที่ไม่เข้าสองหมวดแรก | `PCSF_ABC.csv`, `notes.xlsx`, `old_PCSF.xlsx`, `wafer.png` |

ข้อควรรู้

- ระบบตรวจ Map Layout File ก่อน ไฟล์ชื่อ `PCSF_layout.xml` จึงอยู่ในหมวด Map Layout File
- ไฟล์ PCSF ที่ไม่ใช่ Excel เช่น `PCSF_ABC.csv` หรือ `PCSF_ABC.pdf` อยู่ในหมวด Other
- ไฟล์ Excel ที่ชื่อไม่ได้ขึ้นต้นด้วย `PCSF` เช่น `notes.xlsx` หรือ `old_PCSF.xlsx` อยู่ในหมวด Other

## เห็นได้ที่ไหน

- แท็บ **Attachments** ของ Request Detail (คำขอที่ส่งแล้ว)
- ส่วน **Attachments** ใต้ Requester Information ของ Draft และในหน้า Draft Management ของ Admin

ไฟล์แสดงเป็น 3 กลุ่มเรียงตามลำดับ Map Layout File, FPC Layout File, Other
หัวข้อแต่ละกลุ่มมีจำนวนไฟล์ในวงเล็บ เช่น "Map Layout File (2)" กลุ่มที่ไม่มีไฟล์จะขึ้นข้อความว่าไม่มีไฟล์
เช่น "No FPC Layout Files." การอัปโหลด ดาวน์โหลด ดูรูป และลบไฟล์ ทำได้เหมือนเดิมในทุกกลุ่ม

ไฟล์ที่เลือกไว้ในหน้า New Request ก่อนบันทึกครั้งแรกยังไม่แบ่งกลุ่ม เพราะยังไม่ได้อัปโหลดเข้า NAS

## ไม่มีอะไรย้ายบน NAS

- ไฟล์ยังอยู่ในโฟลเดอร์เดียวของคำขอ `[Target 12NC Desc]_[ID]` ชื่อไฟล์ไม่เปลี่ยน และไม่มีโฟลเดอร์ย่อยตามหมวด
- Imported Request (คำขอที่โหลดจาก Initial Data Load) และไฟล์ที่วางลงโฟลเดอร์บน NAS โดยตรงถูกแบ่งหมวดทันทีที่เปิดดู
  ไม่ต้องย้ายหรือแปลงข้อมูลใด ๆ
- ถ้าไฟล์ไปอยู่ผิดกลุ่มเพราะตั้งชื่อไม่ตรงกฎ ให้แก้ชื่อไฟล์ เช่น ลบไฟล์แล้วอัปโหลดใหม่ด้วยชื่อที่ถูกต้อง
  หรือเปลี่ยนชื่อในโฟลเดอร์บน NAS โดยตรง (ไฟล์ที่เปลี่ยนชื่อบน NAS จะแสดงเป็น "Added on the NAS" และไม่มีชื่อผู้อัปโหลด)

## การเปลี่ยนกฎเป็นการแก้โค้ด

รายการนามสกุลไฟล์และคำขึ้นต้น `PCSF` อยู่ในโค้ดของระบบ (`backend/src/requests/attachment-category.ts`)
ไม่มีหน้าตั้งค่าให้ Admin แก้ หากทีม PSF ต้องการเพิ่มหรือลดนามสกุล ต้องแจ้งผู้พัฒนาให้แก้โค้ดและติดตั้งระบบใหม่

## รายการตรวจก่อน go-live

- [ ] หมวดไฟล์แนบไม่มีค่าที่ต้องตั้งหลัง Initial Data Load
- [ ] เปิด Imported Request ที่มีไฟล์บน NAS อย่างน้อย 2 รายการ แล้วดูแท็บ Attachments ว่าไฟล์ E142 / `.dpl` / `.lay`
      อยู่ใน Map Layout File และไฟล์ Excel ที่ขึ้นต้นด้วย PCSF อยู่ใน FPC Layout File
- [ ] ถ้าทีม PSF ต้องการเปลี่ยนรายการนามสกุล ให้แจ้งผู้พัฒนาก่อนวัน go-live เพราะเป็นการแก้โค้ด
