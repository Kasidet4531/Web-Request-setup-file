# Autofill: สีไฮไลต์และ Select All

หน้านี้สำหรับผู้ดูแลระบบ (Admin) อธิบายสีที่ผู้ขอ (Requester) เห็นเมื่อ Autofill เติมช่องในฟอร์มให้
และปุ่ม **Select all** / **Clear all** ในหน้า **Auto-fill Rules** ใช้กับระบบตั้งแต่ 24 ตุลาคม 2026
(issue #114) คำศัพท์เป็นไปตาม [GLOSSARY.md](../../GLOSSARY.md) รายละเอียดทางเทคนิคอยู่ที่
[current implementation](../current-implementation.md#autofill-audit-and-export)

## สีไฮไลต์ในฟอร์มของผู้ขอ

เมื่อผู้ขอกรอกช่อง trigger ของ Auto-fill Rule ที่เปิดใช้ (Active) ระบบหา PSF Request ที่ Completed
ล่าสุดที่มีค่า trigger ตรงกัน แล้วเติมค่าลงในช่องเป้าหมาย (Fill target fields) ที่ยังว่างอยู่
ช่องที่ผู้ขอพิมพ์ไว้แล้วจะไม่ถูกเขียนทับ ช่องที่ระบบเติมให้และช่องที่ผู้ขอแก้ภายหลังจะมีสีต่างกัน
เพื่อให้ผู้ขอตรวจก่อนบันทึกและส่งคำขอ

| สถานะ | สิ่งที่เห็น | ความหมาย |
| --- | --- | --- |
| **Auto-filled** | แถวของช่องเป็นพื้นสีฟ้า มีกรอบสีน้ำเงิน และป้าย "Auto-filled" สีน้ำเงิน | Autofill เติมค่าช่องนี้ให้ ผู้ขอยังไม่ได้แก้ |
| **Edited by user** | แถวของช่องเป็นพื้นสีส้มอ่อน มีกรอบสีส้มเข้ม และป้าย "Edited by user" สีส้มเข้ม | Autofill เติมค่าให้แล้ว แต่ผู้ขอแก้ค่าหลังจากนั้น |
| ไม่มีสี | แถวปกติ ไม่มีป้าย | Autofill ไม่ได้เติมช่องนี้ |

ข้อควรรู้

- ป้ายข้อความ "Auto-filled" และ "Edited by user" ยังอยู่คู่กับสีเสมอ ผู้ที่แยกสีไม่ได้หรือใช้
  โปรแกรมอ่านหน้าจอจึงรู้ความหมายจากข้อความได้
- สีใช้ได้ทั้งธีมสว่าง (Light) และธีมมืด (Dark) ตัวอักษรบนพื้นสีมีความต่างของสี (contrast) อย่างน้อย
  4.5:1 กรอบของช่องและกรอบของแถวอย่างน้อย 3:1 และกรอบโฟกัสของแป้นพิมพ์ยังเห็นชัด
- ถ้า Autofill ทำงานอีกครั้ง เช่น ผู้ขอเปลี่ยนค่า trigger ระบบเติมได้เฉพาะช่องที่ว่างอยู่ ช่องที่เติมรอบนี้
  เปลี่ยนเป็นสีฟ้า (แม้ก่อนหน้าจะเป็นสีส้ม) ช่องอื่นคงสีเดิม
- ช่องข้อมูลผู้ขอ (Requester, Requester Name, Modified By) และ Start Date ไม่ถูกเติมและไม่มีสี
  แม้จะเลือกเป็น Fill target field ไว้
- สีและป้ายเขียนไว้ในโค้ด (`frontend/src/index.css`) ไม่มีหน้าตั้งค่าให้ Admin เปลี่ยนสี

## สีหายไปเมื่อไร

สีเป็นของฟอร์มที่เปิดอยู่เท่านั้น **ระบบไม่บันทึกสีไว้ที่ใดเลย** ทั้งในฐานข้อมูล ในคำขอ ใน Audit History
และในไฟล์ Excel

- กด **Save draft changes** ในหน้า Draft ที่เปิดอยู่: บันทึกค่าแล้วสีและป้ายยังอยู่เหมือนเดิม
- กด **Save draft request** ครั้งแรกจากหน้า **New Request**: ระบบพาไปหน้า Draft ที่เพิ่งสร้าง และสีกับป้าย
  ตามไปด้วยเหมือนฟอร์มยังเปิดอยู่ ผู้ขอจึงตรวจต่อได้ก่อนกด Submit (ระบบส่งต่อสีไว้ในหน่วยความจำของ
  เบราว์เซอร์แท็บนั้นครั้งเดียว ไม่ได้บันทึกที่ใด)
- โหลดหน้าใหม่ (Reload / F5) หรือเปิด Draft นั้นอีกครั้งภายหลัง (เช่น จาก My Drafts หรือ Requests):
  ทุกช่องแสดงค่าที่บันทึกไว้ตามปกติ ไม่มีสีหรือป้าย
- กด **Reload draft**, **Upgrade** Form Version ของ Draft หรือ **Cancel** ระหว่าง Edit information:
  สีหายเช่นกัน

## Select all และ Clear all ในหน้า Auto-fill Rules

ใช้เมื่อต้องการให้ Auto-fill Rule เติมช่องจำนวนมากโดยไม่ต้องติ๊กทีละช่อง

1. เปิด **Administration** แล้วเลือก **Auto-fill Rules**
2. กด **Create rule** หรือกด **Edit** ที่กฎที่มีอยู่
3. เลือก **Autofill trigger field** ก่อน
4. ในกล่อง **Fill target fields** กด **Select all** ระบบติ๊กทุกช่องที่เป็นเป้าหมายได้ คือทุกช่องของฟอร์ม
   Requester Information ที่ Active ยกเว้นช่อง trigger เอง ช่องที่ติ๊กไว้แล้วยังอยู่ลำดับเดิม
5. เอาเครื่องหมายออกจากช่องที่ไม่ต้องการให้เติม เช่น Request To หรือช่องที่ต้องกรอกใหม่ทุกครั้ง
6. ดูจำนวนที่เลือกข้างปุ่ม เช่น "12 of 40 fields selected" แล้วกด **Create autofill rule** หรือ
   **Save autofill rule**

กด **Clear all** เพื่อเอาเครื่องหมายออกทุกช่อง รวมถึงช่องที่ขึ้นว่า "Removed target field … deselect before
saving" (ช่องที่ถูกลบออกจากฟอร์มแล้ว) จำนวนที่แสดงนับเฉพาะช่องที่ยังอยู่ในฟอร์ม

การบันทึกหลังกด Select all ได้กฎเหมือนติ๊กทุกช่องด้วยมือ และตรวจเหมือนเดิมทุกอย่าง: ต้องมีอย่างน้อย
1 ช่อง ช่องที่ถูกลบจากฟอร์มต้องเอาออกก่อนบันทึก และ trigger หนึ่งช่องมีได้กฎเดียว ถ้าบันทึกไม่ผ่าน
หน้าต่างยังเปิดอยู่และช่องที่เลือกไว้ยังอยู่ครบ

## รายการตรวจก่อน go-live

- [ ] Initial Data Load ลบ Auto-fill Rules ทั้งหมด หลังโหลดข้อมูลให้สร้าง Auto-fill Rules ใหม่ทุกกฎ
      (trigger, Fill target fields และสถานะ Active) ตามที่ใช้ตอนทดสอบ ใช้ **Select all** แล้วเอาช่องที่ไม่ต้องการออก
- [ ] ตรวจว่าแต่ละกฎไม่ได้เลือกช่องที่ผู้ขอต้องกรอกใหม่ทุกครั้งเป็นเป้าหมาย
- [ ] ทดลองเปิด New Request ด้วยบัญชี Requester กรอก trigger ของกฎหนึ่งกฎ ตรวจว่าช่องที่ถูกเติมเป็นสีฟ้า
      พร้อมป้าย "Auto-filled" แก้ช่องหนึ่งแล้วเห็นสีส้มพร้อมป้าย "Edited by user" ทั้งธีม Light และ Dark
- [ ] กด Save draft request แล้วตรวจว่าหน้า Draft ที่เปิดขึ้นยังแสดงสีและป้ายเดิม จากนั้นโหลดหน้าใหม่ ตรวจว่าค่ายังอยู่
      และไม่มีสีหรือป้ายเหลืออยู่ แล้วลบ Draft ทดลองนั้น
