Historical form preview: layout A

Open index.html in your browser. No installation, account or internet connection
is needed. The button at the top right switches between light and dark mode.

This preview uses layout A: labels on the left, values on the right, with the
complete historical form shown. Orange rows mark fields changed in that update.
Each edited field has a label, a jump link and its earlier value.

Under 'Choose an example', select a form edit or a Status change. The Status
example shows the values before and after the update. All values and Status
names are made-up examples.

The file contains no organisation branding, real records, API connection,
credentials or external assets. Nothing has been uploaded or published.
